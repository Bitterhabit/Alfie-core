Cloud Coding Agents & Privacy Controls

Connect Gemini API and ChatGPT (OpenAI) for coding, with strictly optional per-provider access to your private sections.

⚠ Privacy Warning — External Cloud Providers

Enabling Gemini API or ChatGPT sends your chat prompts outside your local Alfie Core to Google or OpenAI servers. Access to your private sections (Emails, Calendar, Personal Journal, Garden Memories, and Dashboard) is strictly blocked by default and completely optional — enforced on the server before any request leaves Alfie.

API keys are never entered in the browser. Configure GEMINI_API_KEY and OPENAI_API_KEY on your server environment or in Settings > Secrets.
